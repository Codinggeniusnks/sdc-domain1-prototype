# M4 Cost Policy, Thresholds & Disclaimers v1.1.0

**Reference Milestone**: Stage 12C Remediation (Audit Finding M4-P3-01)  
**Target Module**: M4 Personalised Reskilling Pathway Engine v1.1.0  
**Status**: COMPLETE & VERIFIED

---

## 1. Audit Context & Regulatory Background

In M4 v1.0.0, the cost classification logic categorized learning resources into cost bands (FREE, FREE_TO_AUDIT, LOW_COST, VARIABLE_PRICE, UNKNOWN). However, Auditor Argon raised a valid fairness and accessibility concern:
1. The numeric boundary defining "LOW_COST" was implicit in code rather than explicitly documented.
2. Labeling an educational resource as "low cost" without an socioeconomic disclaimer could be misinterpreted as a normative policy claim that RM150 is universally affordable for all Malaysian workers, including B40 households and displaced entry-level clerks.

---

## 2. Low-Cost Threshold & Configuration Definition

In M4 v1.1.0, the threshold is explicitly governed in `data/reskilling/m4_scoring_config_v1_1.json`:

```json
{
  "cost_policy": {
    "currency": "MYR",
    "low_cost_threshold_myr": 150.0,
    "operational_disclaimer": "For this prototype, LOW_COST is operationally defined as a verified direct resource price of RM150 or less. This is a product classification threshold, not a claim that RM150 is universally affordable. Actual affordability depends on individual socioeconomic context, employer sponsorship, and national subsidy schemes such as HRD Corp.",
    "cost_categories": {
      "FREE": "Zero cost for access and completion materials",
      "FREE_TO_AUDIT": "Free course audit available; optional paid certificate",
      "LOW_COST": "Direct verified cost <= RM150",
      "VARIABLE_PRICE": "Subscription model, tiered pricing, or institutional contract",
      "UNKNOWN": "Pricing unverified or dynamic"
    }
  }
}
```

### Threshold Justification
The RM150 boundary represents a pragmatic operational threshold benchmarked against:
1. Entry-level exam voucher subsidies in Malaysia (e.g., MDEC eUsahawan and TVET vouchers typically covering up to RM150–RM300).
2. Typical monthly digital learning subscriptions (e.g., Coursera Plus single-month promotional passes or LinkedIn Learning vouchers).
3. Micro-credential lab fees for single competencies.

---

## 3. Mandatory Operational Policy Disclaimer Integration

Every pathway generated by M4 v1.1.0 embeds this threshold and formal operational disclaimer directly within its `verified_cost_summary` payload:

```json
{
  "verified_cost_summary": {
    "minimum_verified_cost_myr": 0.0,
    "maximum_verified_cost_myr": 0.0,
    "currency": "MYR",
    "low_cost_threshold_myr": 150.0,
    "cost_preference_applied": "FREE_FIRST",
    "operational_disclaimer": "For this prototype, LOW_COST is operationally defined as a verified direct resource price of RM150 or less. This is a product classification threshold, not a claim that RM150 is universally affordable. Actual affordability depends on individual socioeconomic context, employer sponsorship, and national subsidy schemes such as HRD Corp.",
    "unknown_cost_items_count": 0,
    "unknown_cost_items": []
  }
}
```

### Handling of Unknown and Variable Pricing
- If a recommended resource carries `VARIABLE_PRICE` or `UNKNOWN` status, it cannot be silently omitted or assigned a zero cost.
- It is added to `unknown_cost_items`, incrementing `unknown_cost_items_count`.
- A confidence-reducing flag `UNKNOWN_PRICING_FLAG: Resource ... has unverified pricing` is automatically appended to `pathway_evidence_confidence.confidence_reducing_flags`.
- In the production catalog (36 courses), zero resources have unknown pricing.
